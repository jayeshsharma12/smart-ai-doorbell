
# Smart AI Doorbell with Person Detection

## Project Description
A smart doorbell system using ESP32-CAM
with camera-based monitoring and person detection.

## Hardware Components
- ESP32-CAM AI Thinker
- OV2640 Camera
- Push Button
- Buzzer
- NPN Transistor
- Resistor

## Features
- Camera image capture
- Wi-Fi connectivity
- Web-based monitoring
- Remote doorbell activation
- Person detection (planned)

## Development Status
Version 1: Basic camera and doorbell functionality.
AI person detection: Under development.
